## 1. 개요 및 요구사항 검토

### 1.1 대상 문서 확인
- **원본 교재**: *Lessons In Electric Circuits, Volume III – Semiconductors* (Tony R. Kuphaldt 저, 5th Edition)
- **라이선스**: 공식 웹 교재의 [Appendix 3](https://www.ibiblio.org/kuphaldt/electricCircuits/Semi/SEMI_A3.html)는 Creative Commons Attribution 4.0 International (CC BY 4.0)을 명시한다. 원문·번역문을 배포할 때 저자·원본 링크·라이선스 링크·변경 사실을 표시한다. 로컬 `SEMI.pdf`의 판본과 라이선스 표기는 콘텐츠 추출 전에 별도 대조한다.
- **파일 현황**: `SEMI.pdf` (약 535페이지, 총 13개 챕터 및 부록)

### 1.2 핵심 요구사항 분석
1. **챕터별 핵심 요약**: 500페이지가 넘는 방대한 이론 및 수식을 직관적인 핵심 개념(Key Takeaway), 동작 원리, 공식 정리 위주로 정제.
2. **도식화 및 인터랙티브 애니메이션**:
   - 텍스트와 정적 회로도만으로는 이해하기 어려운 캐리어(전하)의 이동, 공핍층(Depletion Region) 형성, 밴드갭(Band Gap), 트랜지스터 바이어스 및 전류 흐름, Op-Amp 피드백 동작 등을 Canvas/SVG 애니메이션으로 시각화.
3. **외부 전문 자료 보충**:
   - 교재에서 미완성(PENDING/INCOMPLETE)으로 표시된 부분(Chapter 5, 6, 9의 일부 고주파/RF 및 제어 회로 등) 및 현대 반도체 소자 내용에 대해 신뢰도 높은 학술/교육 자료(PhET, Falstad, HyperPhysics, AllAboutCircuits 등) 검색 및 링크 연계.
4. **결과물 형태**:
   - 웹 브라우저에서 바로 학습할 수 있는 **반응형 인터랙티브 웹 플랫폼(SPA / Interactive Document Platform)**.
5. **교재 원문·번역 열람**: 핵심 요약만으로 이해하기 어려운 개념은 교재의 해당 절로 이동해 영어 원문과 충실한 한국어 번역을 문단·수식·그림 단위로 대조할 수 있게 한다. 번역과 프로젝트의 별도 해설을 명확히 구분한다.
6. **검증된 보충 해설**: 교재 설명만으로 부족한 지점을 기록하고 외부 자료를 조사한 뒤, 출처를 추적할 수 있는 쉬운 한국어 해설을 제작하여 관련 교재 절·요약·랩에 연결한다. 외부 검색과 콘텐츠 발행은 편집·검토 과정으로 운영하며 방문자 화면에서 검증되지 않은 검색 결과를 자동 게시하지 않는다.

## 3. 웹 애플리케이션 아키텍처 및 기술 스택

### 3.1 기술 스택 선정
- **아키텍처**: 경량 Standalone 모던 웹 SPA (Single Page Application)
- **UI 및 스타일**: HTML5, Tailwind CSS (CDN), Lucide Icons
- **수식 렌더링**: KaTeX (CDN 기반 고속 렌더링)
- **시뮬레이션 및 그래픽**: HTML5 Canvas API, 동적 SVG, Chart.js
- **실행 환경**: 별도 복잡한 빌드/번들 과정 없이 정적 파일 배포 및 브라우저 직접 구동 가능
- **교재·해설 데이터**: 장/절별 원문·번역·보충 해설을 별도 정적 콘텐츠 파일로 분리한다. 절·문단의 안정적인 ID, 출처·판본·검토 상태를 보존하고 기존 `chapters-data.js`에는 목차와 연결 정보만 둔다.

## 4. 단계별 실행 계획 (Roadmap)

### 🚀 Phase 1: 플랫폼 기반 구축 및 프로토타입 (Ch 1 ~ Ch 3)
- **웹 플랫폼 셸(Shell) 구축**: 다크/라이트 모드 지원, 반응형 사이드바 내비게이션, 수식(KaTeX) 및 다이어그램 레이아웃
- **Ch 1 (증폭기/데시벨/감쇠기)**: 데시벨 계산 인터랙티브 및 증폭 개념 시각화
- **Ch 2 (고체 소자 이론)**: 에너지 밴드갭(도체/반도체/부도체) 및 P-N 접합 형성 파티클 애니메이션
- **Ch 3 (다이오드/정류기)**: 다이오드 순/역방향 전하 이동, 전파 브리지 정류기 동적 전류 경로 애니메이션

### 🚀 Phase 2: 트랜지스터 및 핵심 능동 소자 (Ch 4 ~ Ch 6)
- **교재 읽기·보충 해설 확장**: 승인된 콘텐츠 제작 기준에 따라 Ch 4~6의 원문·번역과 개념별 보충 해설을 절 단위로 발행한다.
- **Ch 4 (BJT)**: NPN 트랜지스터 내부 전자/정공 흐름 애니메이션, 부하선(Load Line) Q-point 시뮬레이터
- **Ch 5 (JFET)**: 게이트 전압에 따른 채널 수축(Pinch-off) 인터랙티브
- **Ch 6 (MOSFET)**: MOS 커패시터 및 반전층 형성, 교재의 미완성 부분 외부 자료 보충

### 🚀 Phase 3: 전력 제어 및 연산 증폭기 (Ch 7 ~ Ch 8)
- **교재 읽기·보충 해설 확장**: Ch 7~8에 동일한 출처·번역·검토 절차를 적용한다.
- **Ch 7 (사이리스터/SCR/TRIAC)**: 2-트랜지스터 래칭 재생 피드백 애니메이션, AC 위상 제어(조명 디머) 초핑 파형 시각화
- **Ch 8 (Op-Amp)**: 지렛대(Lever) 비유 인터랙티브 모델, 미분기/적분기 실시간 파형 변환기

### 🚀 Phase 4: 응용 회로 및 진공관, 종합 완성 (Ch 9 ~ Ch 13)
- **교재 읽기·보충 해설 확장**: Ch 9~13의 절별 콘텐츠를 발행하고 전체 목차의 누락·출처·연결 상태를 점검한다.
- **Ch 9 (실제 회로 & 아날로그 연산)**: 차량 주행(위치-속도-가속도) 아날로그 컴퓨터 미분/적분 시각화
- **Ch 10~12 (필터 & 모터 드라이브)**: PWM 듀티비 시뮬레이션 및 H-브리지 모터 제어
- **Ch 13 (진공관)**: 3극관/5극관 열전자 흐름 및 고조파 왜곡 특성 비교
- **외부 리소스 연계**: Falstad 실시간 회로 시뮬레이터 직접 실행 링크, PhET 반도체 시뮬레이션 연계
- **배포 및 패키징**: 단일 폴더 또는 정적 호스팅(GitHub Pages / 로컬 서버) 완비

### 5.5 화면 검증 도구 (2026-10-10)

`tests/browser/phase1-capture.spec.cjs`와 `playwright.config.cjs`를 추가했다. 사용자 개발 환경 또는 허용된 CI에서 `npm run capture:phase1`을 실행하면 로컬 서버를 시작하고 데스크톱 셸·Ch 1~3의 주요 조작 상태·320px 모바일 화면을 `artifacts/phase1/`에 캡처한다. 화면 넘침, 기본 조작 결과, JavaScript 오류, Ch 3 PhET 링크 주소를 함께 검사한다. 애니메이션은 정해진 시각에 멈춰 비교 가능한 프레임을 만든다. 스크립트 작성 및 구문 검사만 완료했으며, 이 세션의 브라우저 보안 정책으로 **실제 실행과 생성 이미지 검토는 아직 수행하지 않았다.** 캡처 실행 뒤 PNG를 검토하고 실패 항목을 수정해야 5.4의 종료 보류를 해제할 수 있다.

### 5.6 첫 캡처 결과 검토 (2026-10-10)

사용자 환경에서 생성된 PNG 31개와 Playwright의 `passed` 결과를 확인했다. 데스크톱 탐색, Ch 1 파형·클리핑, Ch 3 양·음 반주기와 평활 파형, PhET 카드 주소, 모바일 내비게이션·완료 표시가 캡처됐다. 스크립트의 조작·가로 넘침·JavaScript 오류 검사는 통과했다. 이미지 검토에서 세 가지 표시 결함을 발견해 소스를 수정했다.

1. Ch 2 밴드 뷰의 전자 점이 원자가대가 아닌 밴드갭 안에 나타났다. 초기 좌표와 재료 전환 시 좌표 재설정을 수정했다.
2. Ch 2 P-N 접합 캔버스 왼쪽 아래에 내용 없는 정보 상자가 보였다. 빈 오버레이를 제거했다.
3. 320px Ch 3 브리지 회로에서 단자·라벨·스코프가 겹쳤고 데스크톱 I-V 축 라벨이 동작점과 가까웠다. 모바일에는 세로 회로/스코프 배치를 적용하고 I-V 라벨 위치를 조정했다.

이 수정은 JavaScript 구문 검사와 Canvas 스모크 검사를 통과했다. **기존 PNG는 수정 전 결과**이므로 `npm run capture:phase1`을 다시 실행해 새 이미지에서 세 결함이 해소됐는지 검토해야 한다. 외부 PhET/ Falstad 실습의 실제 실행과 Phase 1 범위 결정은 여전히 남아 있다.

## 6. 교재 읽기와 보충 해설 확장 계획 (검토안, 2026-10-10)

### 6.1 요구사항 해석과 기존 구성과의 관계

현재 네 탭은 개념을 빠르게 이해하고 실험하는 데 초점을 둔다. 새 **교재 원문·번역** 탭은 저자의 설명을 생략 없이 추적하는 읽기 경로다. **심층 탐구**에는 교재의 문장을 그대로 번역한 내용과 구별되는 프로젝트 자체의 보충 해설을 둔다. **추천 보충 자료**는 해설의 근거가 되는 자료와 직접 실습 가능한 링크를 보여준다. 따라서 한 개념에서 `요약 → 교재 해당 절 → 보충 해설 → 랩/출처`로 이동할 수 있어야 한다.

### 6.2 교재 원문·번역 페이지

| 영역 | 계획 |
| :--- | :--- |
| 탐색 | 장 → 절 → 소절 목차, 절 URL/해시 직접 이동, 요약·랩에서 해당 문단으로 연결, 이전/다음 절 이동을 제공한다. 교재에 없는 절은 빈 본문 대신 `미작성`을 표시한다. |
| 읽기 화면 | 영어 원문과 한국어 번역을 문단별로 대응시킨다. 데스크톱은 병렬, 모바일은 세로 배치/언어 전환을 제공한다. 원문/번역 표시와 글자 크기, 수식, 그림·캡션, 표, 각주를 확인할 수 있게 한다. |
| 번역 원칙 | 교재의 주장·조건·단위·수식·그림 참조를 보존한다. 직역으로 의미가 흐려지는 부분은 별도 번역자 주석을 달고, 원문 오류 의심이나 현대적 보완 내용은 번역문 안에 섞지 않고 보충 해설에 둔다. 주요 용어는 장 간 공통 용어집으로 통일한다. |
| 출처 표시 | 절마다 원본 웹 URL, PDF 판본·쪽수(확인된 경우), 저자, CC BY 4.0 링크, 번역·수정 사실, 콘텐츠 갱신일을 표시한다. 그림 등 개별 요소의 권리·출처가 다른 경우 따로 확인한다. |
| 상태 표시 | `미작성 / 초안 / 기술·번역 검토 완료 / 공개` 상태와 절별 커버리지를 보여준다. 초안은 완성된 번역으로 오인되지 않게 한다. |

먼저 공식 [Volume III 목차](https://www.ibiblio.org/kuphaldt/electricCircuits/Semi/index.html)의 HTML을 기준 원본 후보로 삼고 로컬 `SEMI.pdf`의 발행 정보·절 구성·라이선스를 대조한다. HTML에서 제목·문단·수식을 구조적으로 추출하되 PDF는 쪽수·그림 대조에 사용한다. 추출 오류, 수식 누락, 회로도 방향, 캡션 불일치는 사람이 교정한다. 전체 535쪽의 일괄 번역을 완료 전제로 삼지 않고 절 단위로 축적한다.

### 6.3 보충 자료 조사와 해설 제작 흐름

1. **이해의 빈틈 등록:** 교재의 절/문단과 질문을 연결한다. 예: “공핍층에서 이동 캐리어는 왜 줄어드는가?” 요약, 번역, 랩만으로 답할 수 있는지 확인한다.
2. **자료 검색·선별:** 대학 강의자료, 학술 원문, 기관 교육자료, 소자 제조사의 데이터시트·애플리케이션 노트, 검증 가능한 시뮬레이션을 우선한다. 자료마다 제목, 작성자·기관, URL, 발행/갱신일(알 수 있는 경우), 확인일, 관련 주장·조건을 기록한다. 검색 순위나 자료의 인지도만으로 정확성을 판단하지 않는다.
3. **교차 검증:** 수식의 가정, 회로 극성, 단위, 적용 소자·동작 영역을 교재 및 독립 자료와 대조한다. 자료 간 해석이 다르면 조건 차이를 밝히고 해결되지 않은 주장은 공개하지 않는다.
4. **쉬운 해설 작성:** 학습 질문 → 직관적 설명 → 회로/도식 또는 수치 예제 → 수식과 적용 조건 → 흔한 오해 → 관련 랩 순으로 구성한다. `교재 원문/번역`, `외부 자료의 주장`, `프로젝트의 해설·추론`을 화면과 데이터에서 구별한다.
5. **권리·링크·편집 검토:** 외부 문장·이미지는 사용 허락을 확인한 경우에만 재사용한다. 그 외에는 자체 문장/도식을 작성하고 원 자료로 연결한다. URL이 특정 콘텐츠로 열리는지, 로그인·플러그인 없이 볼 수 있는지, 링크 설명이 실제 내용과 맞는지 확인한다. 기술·번역·출처 검토를 거쳐 공개한다.

외부 검색은 **콘텐츠 제작 시의 조사 절차**다. 앱에는 검토된 해설과 출처만 정적 콘텐츠로 포함한다. 실시간 웹 검색 또는 자동 생성·게시 기능은 이번 범위에 포함하지 않으며, 별도 필요성과 운영 기준을 검토한 뒤 결정한다.

### 6.4 콘텐츠 구조와 운영 기준

- 교재 콘텐츠는 장/절별 파일로 관리하고 `chapterId`, `sectionId`, 안정적인 `paragraphId`, 원문, 번역, 수식·그림 참조, 원본 URL, PDF 쪽수(검증 시), 판본 식별자, 번역자/검토자, 상태·검토일을 기록한다.
- 보충 해설은 `question`, 연결된 `sectionId`/`paragraphId`, 설명·예제·오해, 관련 랩, 주장별 출처 URL/작성자/확인일, 이미지 권리 정보, 검토자·상태를 기록한다. 기존 추천 자료 카드와 한 출처 목록을 공유해 설명과 링크가 어긋나지 않게 한다.
- 출처 원본의 파일·해시 또는 판본 식별 정보와 수집일을 남겨 교재가 개정되어도 번역의 기준을 추적한다. 새 판본에서는 절/문단 차이를 확인하고 영향을 받는 번역·해설만 다시 검토한다.
- 정적 파일 분리와 장/절 단위 로딩으로 초기 로딩량을 제한한다. 콘텐츠에 HTML을 허용할 경우 정제 규칙을 적용하고, 우선은 안전한 구조화된 텍스트·수식·그림 참조를 사용한다.

### 6.6 사용자 검토 결정 지점

1. 새 탭 이름과 병렬/모바일 읽기 방식, 원문·번역·보충 해설의 구분 방식.
2. 파일럿의 대표 절 선정과 Ch 1~3 전체 번역을 진행할 우선순위. 파일럿 결과가 나온 뒤 전체 범위·일정을 재산정한다.
3. 외부 자료의 출처 등급과 보충 해설의 편집 승인 기준. 기술적 이견이나 사용 권리가 불명확한 자료는 공개 전에 해결한다.

이 절은 **계획안**이다. 사용자의 내용 검토 후 설계·파일럿 구현에 착수한다.

### 6.7 Ch 1 한정 첫 구현 (2026-10-10)

사용자 결정에 따라 우선 Ch 1만 개발한다. 다섯 번째 **교재 원문·번역** 탭에 Ch 1의 7개 주요 절에서 선정한 원문 문장과 한국어 번역, 별도 보충 설명을 연결했다. 공식 교재 전체 본문과 CC BY 4.0 링크를 제공하며, 화면에 **부분 공개·절 전체 미번역**임을 명시했다. 기존 핵심 요약과 심층 탐구에서 새 탭으로 이동할 수 있다.

심층 탐구에는 전압비의 20 log 조건과 dBm의 1 mW 기준을 설명하는 자체 보충 해설을 추가했다. Analog Devices와 Keysight의 자료를 근거 링크로 연결했다. JavaScript 구문 검사, 기존 스모크 검사와 Ch 1 읽기 화면의 데스크톱·320px 브라우저 검사를 통과했다.

**남은 Ch 1 작업:** 교재의 나머지 문단·수식·그림을 절별로 번역·대조하여 부분 공개 표기를 해제한다. 로컬 PDF와 공식 HTML의 판본을 확인하고, 번역·기술 검토자 승인을 기록한다. Ch 2 이후의 읽기 콘텐츠는 이번 개발 범위에 포함되지 않는다.

### 6.8 Ch 1 후속 진행 기록 (2026-10-10)

기존 파일럿 커밋 `5b8c491` 뒤에 로컬 PDF를 확인했다. 표지의 판본은 **Fifth Edition, last update November 06, 2021**, 전체 535쪽이며 Ch 1은 PDF 뷰어 기준 10~35쪽(교재 표기 1~26쪽)이다.
